如何测试确实有发送验证码？

  • 之前是调用 UserMailer.welocme_email(code).deliver 这个方法去发送邮件的
  • 需要测试验证访问 /api/v1/validation_codes 确实调用了发送验证码的方法，就是证明确实发送了验证码
  • 单元测试不测第三方服务，比如邮件接口服务，支付接口服务，只测试本单元的功能，即调用发送邮件的方法

class Api::V1::ValidationCodesController < ApplicationController
  def create
    code = SecureRandom.random_number.to_s[2..7]
    validation_code = ValidationCode.new email: params[:email], kind: "sign_in", code: code
    if validation_code.save
      UserMailer.welcome_email(validation_code.email)
      render status: 200
    else
      render json: { errors: validation_code.errors }, status: 422
    end
  end
end

class ValidationCode < ApplicationRecord
  # email必填
  validates :email, presence: true
  # 钩子函数
  after_initialize :generate_code

  def generate_code
    self.code = SecureRandom.random_number.to_s[2..7]
  end
end
  • after_initialize :generate_code 构成名称为 after_initialize 构造函数
  • 被构造后就会去执行generate_code方法
  • 对象实例 ValidationCode.new 执行之后调用 generate_code，就自动会有 code

4. 如何对记录进行排序 ⇧

user_mailer.rb中 validation_code = ValidationCode.find_by_email(email) 这样查找email存在问题

  • 比如同一个用户登录了10次，就创建了10个 validation_code，其中的 email 都是这个用户的
  • 需要找到最新的一个，代码中的逻辑就是需要在 find_by_email 前对 ValidationCode 做一个排序

app/mailers/user_mailer.rb

1
2
3
4
5
6
7

class UserMailer < ApplicationMailer
  def welcome_email(email)
    validation_code = ValidationCode.order(created_at: :desc).find_by_email(email)
    @code = validation_code.code
    mail(to: email, subject: "山竹记账验证码")
  end
end
  • `.order(created_at: :desc) 创建时间降序排列
  • find_by_email 只会找第一个
  • 找到最新的邮箱对应的验证码发送
  • 由于依赖了第三方服务，这个功能也是不好测试的

为什么要把 after_initialize 改为 before_create ⇧

  • 因为 after_initialize 会在每次初始化对象后执行
  • 而 before_create 只在创建数据库项目时执行，后者才是我们需要的

6. 如何防止重复发送验证码 ⇧

实现60秒内不能重复发送

  • 做后端时的原则，前端不可信，后端必须要做检查，防止各种绕开前端检查的漏洞

思路：每次发送发送验证码之前，看一下刚才有没有发送过验证码

  • 如果刚才有发送过验证码，并且时间是在60秒之内，就返回不能发送

class Api::V1::ValidationCodesController < ApplicationController
  def create
    # 查找60秒内创建的 ValidationCode
    ValidationCode.where(email: params[:email], kind: "sign_in", created_at: 1.minutes.ago..Time.now)
    validation_code = ValidationCode.new email: params[:email], kind: "sign_in"
    if validation_code.save
      render status: 200
    else
      render json: { errors: validation_code.errors }, status: 422
    end
  end
end

class Api::V1::ValidationCodesController < ApplicationController
  def create
    # 查找60秒内创建的 ValidationCode
    if ValidationCode.exists?(email: params[:email], kind: "sign_in", created_at: 1.minutes.ago..Time.now)
      render status: :too_many_requests # 429
      return
    end
    validation_code = ValidationCode.new email: params[:email], kind: "sign_in"
    if validation_code.save
      render status: 200
    else
      render json: { errors: validation_code.errors }, status: 422
    end
  end
end
  • exists?：Ruby里面有一个特点，如果函数返回值的类型是布尔，那么这个函数的结尾就是个问号
  • 这个问号是函数名的一部分
