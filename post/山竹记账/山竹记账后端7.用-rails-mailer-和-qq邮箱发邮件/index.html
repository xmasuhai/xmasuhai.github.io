require "active_support/core_ext/integer/time"

Rails.application.configure do
  config.action_mailer.raise_delivery_errors = true
  config.action_mailer.perform_caching = false
  config.action_mailer.default_url_options = { host: "localhost", port: 3000 }
  config.action_mailer.delivery_method = :smtp
  config.action_mailer.smtp_settings = {
    address:         "smtp.qq.com",
    port:            587,
    domain:          "smtp.qq.com",
    user_name:       "xxx@qq.com",
    password:        Rails.application.credentials.email_password,
    authentication:  "plain",
    enable_starttls: true,
    open_timeout:    10,
    read_timeout:    10 }
end
  • email_password 映射的是邮箱生成的 POP3/IMAP/SMTP/Exchange/CardDAV 服务生成的授权码
  • 确保此处 user_name
    • 和 user_mailer.rb 中设置的 default from: "xxx@example.com" 一致
    • 或者和 app/mailers/application_mailer.rb 中设置的 default from: "xmasuhai@qq.com" 一致

6. Rails 应用重新创建密钥 ⇧

创建密钥分两种情况：

  • 如果你想保留之前创建的 config/master.key 和 config/credentials.yml.enc 两个文件
    • 就直接把之前的文件复制到本项目的 config 里。

  • 如果你之前没有创建过 config/master.key 和 config/credentials.yml.enc 两个文件，就按下面的步骤做：

    1
2
3

    rm config/credentials.yml.enc
# EDITOR="code --wait" rails credentials:edit # 旧版
VISUAL="code --wait" rails credentials:edit

  • 新版运行 VISUAL="code --wait" rails credentials:edit

  • 注意，如果是生产环境，你就在 credentials:edit 后面加上 --environment production 参数

  • 然后，在打开的文件中写入如下内容（其中 xxx 应该是一串密码或者一串随机字符串，具体怎么生成 xxx 要看对应的视频，不记得就回看一下自己的笔记）：

    1
2
3

    secret_key_base: xxx
email_password: xxx
hmac_secret: xxx

  • 这样，就得到了 config/master.key 和config/credentials.yml.enc 两个文件

  • 此时应该提交代码。然后开始写新的代码

7. 总结 ⇧

  • 创建 Mailer 相关文件，命令 bin/rails generate mailer User 自动生成文件
  • 全局配置 app/mailers/application_mailer.rb，发送邮箱改为 default from: "from@example.com"
  • 邮件内容模板 app/views/user_mailer/welcome_email.html.erb
  • 在第三方邮箱服务中设置授权码，将授权码保存到 config/credentials.yml.enc email_password: xxxx
  • 开发环境配置邮件服务器 config/environments/development.rb
    • 添加配置 config.action_mailer.smtp_settings
    • 设置好邮件服务地址、端口 587、用户名邮箱、超时时间等
    • 设置好密码 password: Rails.application.credentials.email_password
  • 修改 app/mailers/user_mailer.rb 中方法传参 def welcome_email(code) @code = code ... end
  • 使用控制台临时发送验证：bin/rails c 命令 UserMailer.welcome_email('123456').deliver
