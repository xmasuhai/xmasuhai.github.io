1. 使用 oh-my-env 开发环境 ⇧

快速启动开发环境 ⇧

  • 下载 oh-my-env-1
  • 使用 VSCode 打开目录
    • 预装 Docker Desktop 加速镜像已配置

    • 已开启 wsl 等
    • 详见 搭建Docker开发环境

  • 遇坑（官方已修复，现无需处理）pnpm build 过程中报第三方打包错误 node_modules/.pnpm/...
    • 处理过程就是报报错信息复制到google/ai中，尝试提示解决方法

3. 修改 build path 部署到 GitHub ⇧

把打包完的代码 dist 部署到 GitHub 或服务器时必须配置 build path

  • 配置规则见 vite文档-开发或生产环境服务的公共基础路径
    • 公共基础路径

  • 在 vite.config.js 里添加 base: '/' 或 base: '/reponame/' 等

    • '/reponame/' 为github中仓库名称

      1
2
3
4
5
6
7
8

      import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'

// https://vitejs.dev/config/
export default defineConfig({
base: '/mangosteen/',
plugins: [vue()],
})

  • 重新打包到 pnpm build

仅是本地预览，直接 base: '/' 就可以了

  • 但是上传 github 会有中间的项目名，base中间写仓库名称即可
  • 之后部署章节中会另外说明配属的配置，可用 node 获取环境变量
  • 目前暂时用不到

提交完开始手动部署 git init;git add .;git commit -m 'first commit'

  • git相关配置见文章 搭建docker开发环境，配置git/github，创建.ssh 密钥
  • 发布到 GitHub
    • 创建github仓库
    • 推到远程仓库
  • 手动开启 GitHub Pages（手动部署可选）
    • 在仓库 settings 中配置 Pages
    • 选择 Branch 为 master，点击 Save
    • 如果直接上传 dist 目录到源代码同一项目仓库（不推荐），则需要在 GitHub Pages 中设置路径 /project-name/dist/
    • 并且需要在 vite.config.ts 中配置 base: '/project-name/dist/'，修改完重新 pnpm build
    • 可以查看 index.html 中资源路径是否已包含 /project-name/dist/
    • 重新上传 dist
    • 另外单独创建网页发布仓库，项目源代码仓库和网页仓库分开：mangosteen-xxx-1-publish
    • 注意修改 vite.config.ts 中配置 base: '/mangosteen-xxx-1-publish/'，修改完重新 pnpm build
    • base 中的目录 必须与仓库名称相同
    • 路径写入项目描述 http://xxx.github.io/project-name/index.html

注意 Vue 的 JSX 转换方式与 React 中 JSX 的转换方式不同，因此不能在 Vue 应用中使用 React 的 JSX 转换

  • 与 React JSX 语法的一些明显区别包括：
    • 可以使用 HTML attributes 比如 class 和 for 作为 props - 不需要使用 className 或 htmlFor。
    • 传递子元素给组件 (比如 slots) 的 方式不同（具名插槽函数）。
  • 使用 TSX 语法时，确保在 tsconfig.json 中配置了 "jsx": "preserve"，这样的 TypeScript 就能保证 Vue JSX 语法转换过程中的完整性

type FComponentProps = {

// ...
}

sendMessage(message: string): void
}

// 具名函数式组件
export function FComponent(
props: FComponentProps,
ctx: SetupContext<Events>
) {
// const { slots, emit, attrs } = ctx
return (
<button
  type="button"
  onClick={() => {
    ctx.emit('sendMessage', props.message)
    Welcome1stPage?.emits['sendMessage']?.('msg child self')
  }}>
  {props.message}
</button>
)
}
// 具名函数式组件的属性和事件，必须后赋值
FComponent.props = {
message: {
type: String,
required: true
}
}
FComponent.emits = {
sendMessage: (value: unknown) => {console.log('FComponent.emits', value,)}
}
// 防止警告，用于DevTools等
FComponent.displayName = 'FComponent'

// 匿名函数式组件
export const AnonymousFC: FunctionalComponent<FComponentProps, Events> = (
props,
context
) => {
return (
<button 
  type="button" 
  onClick={
    () => {
      context.emit('sendMessage', props.message)
      Welcome1stPage?.emits['sendMessage']?.('msg child self')
    }
  }>
  外部数据：{props.message}
</button>
)
}

}
}

return (
